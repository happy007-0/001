# 自驱执行系统（LifeOS）产品需求文档（PRD）

- **版本号**：v0.1（MVP）
- **作者**：叶文亮（wenliang ye）
- **日期**：2025年10月

## 一、总体愿景（最终版目标）
自驱执行系统（LifeOS）的最终目标，是打造一个以“使命导向 + 阶段进程 + AI教练反馈”为核心的个人操作系统，帮助用户将长期使命分解为阶段性路径，再转化为可执行的日/周/月计划，实现全方位的自驱成长与意识进化。

系统将基于用户的使命蓝图与阶段计划，动态生成目标与优先级；通过积分、复盘、AI教练反馈等机制，让用户获得方向感、成就感与自我修正能力；最终以“稳健、直线式成长”方式达成长期人生使命。

### 最终版系统功能构想
1. **云同步与多端协同**：支持账号登录、自动同步任务、日志与积分数据。
2. **AI教练实时对话**：基于用户日记与执行情况，进行实时互动、指导与批评反馈。
3. **意识轨迹数据图**：以图谱形式可视化展示用户的能量流、心态曲线、成长路径与行为复利。
4. **偶像镜像引擎**：AI可根据选定的导师或偶像（如纳瓦尔、马斯克、产品总监型）模拟其思维风格进行指导。
5. **阶段与使命映射**：系统自动将长期使命分解为阶段目标 → 月度OKR → 每日行动计划。
6. **AI能量平衡反馈**：根据任务完成度、心态趋势、注意力泄漏情况，自动调整每日任务负载。
7. **积分与等级体系**：形成长期成长激励循环，包括日积分、连击、阶段成就、长期等级。

## 二、MVP版本目标与范围
MVP版本聚焦在“个人日常可闭环自驱系统”的最小可行形态，目标是让用户在2分钟内完成“设定 → 执行 → 反馈 → 激励”的每日闭环。

本版本仅采用本地运行（localStorage），不涉及云同步或AI模型调用，所有逻辑在前端执行，支持离线使用。

### 核心目标
1. 形成每日可执行闭环：今日三选 → 每日三问 → 自动反馈。
2. 建立积分激励系统：根据任务完成、心态与复盘自动计算积分与等级。
3. 提供即时AI教练反馈：基于当日数据生成Wins、Risks、Next3、OneFix、IdolLens五类反馈。
4. 支持导出/导入JSON备份数据。

### 功能范围
1. **Dashboard（驾驶舱）**：显示总积分、等级、今日完成度、高投产比任务、AI反馈。
2. **Task Matrix（任务矩阵）**：任务录入与投产比计算（R/C/K）。
3. **Today（三选 + 三问）**：每日执行与复盘模块。
4. **AI教练引擎**：本地逻辑生成个性化反馈。
5. **Points（积分页）**：积分、等级、连击状态展示。
6. **Backup（数据页）**：导出/导入功能。

## 三、用户流程
1. 早晨：设定今日三选（系统推荐Top3高投产比任务或用户自选）。
2. 白天：执行任务并勾选完成。
3. 晚上：填写每日三问与心态评分。
4. 系统计算积分并生成AI教练反馈。
5. Dashboard更新积分、等级与连击状态。
6. 用户可导出数据备份，或次日继续循环。

## 四、核心功能需求（概要）

| 模块 | 功能目标 | 用户操作 | 系统行为 | 输出表现 | 边界/异常 |
| --- | --- | --- | --- | --- | --- |
| Dashboard | 展示核心状态 | 进入首页 | 读取数据并计算进度、等级 | 显示积分条、等级徽章、Top3任务、反馈 | 无数据则显示引导提示 |
| Task Matrix | 录入任务并计算投产比 | 输入任务名、R/C/K | 计算R/C*K与优先级 | 列表动态更新颜色标识 | R/C/K缺失时禁用保存 |
| Today-三选 | 聚焦当日关键任务 | 输入或选择3项任务 | 保存当日清单 | Dashboard显示完成进度条 | 任务已完成则不可重复选择 |
| Today-三问 | 复盘当日状态 | 填写Q1–Q3与心态分 | 计算积分并触发AI反馈 | 生成五段反馈文本 | 任一问题未填则不计分 |
| AI Coach | 生成反馈建议 | 提交三问后自动运行 | 分析数据并生成反馈 | 展示Wins、Risks、Next3、OneFix、IdolLens | 数据缺失则输出默认语句 |
| Backup | 导入导出数据 | 点击导出/导入 | 读取/写入localStorage | 弹出成功提示 | 格式错误则提示导入失败 |

## 五、版本规划
- **v0.1**：本地MVP版，支持任务矩阵、三选、三问、AI反馈、积分体系、备份导入导出。
- **v1.0**：正式版，增加趋势图、周/月复盘、注意力泄漏分析。
- **v2.0**：云同步版，支持登录、跨设备数据同步。
- **v3.0**：AI陪练版，支持AI教练实时对话、语义分析、情绪检测。
- **v4.0**：意识实验版，生成意识轨迹图、能量曲线、行为复利指数。
